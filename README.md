# LibroTracker Final Project
This was my final project for a course related to software engineering and microservices transactions. 
As part of this project, we had to establish API connections to external services, make a project that worked, and collaborate in a group to have all our projects collaborate

## About LibroTracker
LibroTracker was my React/Vite/JS project that acted as a project that would track books a person had read, grab quotes from another API service, and collaborate with other students microservices on some level. It was also used to demonstrate usage of Github--adding in potential future uses.
